Software Design and Engineering

For the Software Design and Engineering enhancement, I selected my LCR Dice Game written in C++. The enhancement focused on improving the structure, reliability, and maintainability of the application.

Improvements included stronger input validation, file-access error handling, defensive programming, and restructuring game logic into smaller reusable functions.

Algorithms and Data Structures

The LCR Dice Game was also enhanced to demonstrate my skills with algorithms and data structures. The application uses a vector of Player objects to maintain the ordered collection of players.

Enhancements included standard collection algorithms, modular arithmetic for circular player relationships, efficient vector operations, constant references, and reusable algorithms for managing the game state.

Databases

For the database enhancement, I selected the Travlr Getaways application. The original static travel website was enhanced into a database-driven application using Node.js, Express, and SQLite.

The enhancement includes persistent trip data, a structured database schema, REST API routes, CRUD operations, validation, database constraints, indexing, error handling, and an administrative interface for managing travel information.
